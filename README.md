## 🚀 What I'm Building

### 🧠 Rotici

**An experimental multimodal AI system built around persistent memory, autonomous execution, creativity, and long-term digital identity.**

Rotici began as an attempt to build an AI system from the ground up rather than simply wrapping an existing chatbot interface.

The project explores a modular architecture involving:

- persistent machine memory
- task orchestration and autonomous execution
- semantic retrieval
- local language models
- computer interaction and browser automation
- visual identity and GUI systems
- audio and music generation
- machine learning components
- creative tools
- long-term memory and behavioral continuity

The long-term direction is a persistent digital entity capable of interacting with software, creating digital content, learning from previous work, and operating through multiple interfaces.

**Status:** Active research & development

---

### 📄 AI CV Maker

**An AI-native, mobile-first career workspace for building and adapting professional resumes.**

AI CV Maker is being developed as a full mobile product rather than a simple resume form.

Its architecture is based around a canonical Resume domain model and a deterministic editing system, allowing the interface, AI layer, persistence layer, and export system to operate around the same source of truth.

Core areas include:

- AI-assisted resume creation and editing
- structured resume domain architecture
- deterministic command/reducer workflows
- validated AI patch proposals
- job-targeted resume adaptation
- cover letter generation
- local-first persistence
- account and entitlement systems
- PDF/document export
- multiple resume templates
- Guest / Free / Pro product architecture
- cloud integration through Supabase

**Stack:** React Native · Expo · TypeScript · Supabase · AI APIs

**Status:** In active development toward production release

### 🏙️ BinTown

**An open-world social progression game built on Roblox.**

BinTown starts with a deliberately simple premise:

> You leave prison, nobody wants to hire you, and your first way to survive is collecting trash.

From that foundation, the project is designed to evolve into a persistent city where players can earn money, explore, socialize, own spaces, customize their environment, interact with NPCs, complete quests, and progress economically.

The existing MVP already established the core gameplay foundation.

The broader vision includes:

- open-world city exploration
- trash collection and recycling economy
- player progression
- vehicles
- purchasable and customizable homes
- interactive shops and commercial spaces
- NPC stories and quest chains
- social gathering areas
- day/night systems
- evolving world events
- long-term player economy

**Platform:** Roblox / Luau

**Status:** Public MVP · Further development planned

## 🧠 How I Build

My preferred approach is:

**Domain-First · Local-First · Modular · Testable · AI-Native**

I like separating the core logic of a product from its interface so that the system can evolve without requiring the underlying architecture to be rebuilt every time the UI, AI provider, storage layer, or platform changes.

I use AI heavily as an engineering multiplier — for implementation, auditing, testing, research, and iteration — while keeping product direction, architecture decisions, validation, and final responsibility under human control.
